壹、项目主体
- 练习
  - 练习仿真 lianxi_gazebo
    - launch
      - car_to.launch：启动入口，加载Gazebo场景、小车urdf模型、激光雷达、相机，发布TF、odom，整套仿真的基础启动文件
    - scripts
      - move_obstacle.py：动态障碍物控制脚本，向 Gazebo 发送模型位姿控制指令，驱动仿真环境内障碍物按照预设运动规则运动；同时输出障碍物状态信息给 TEB 规划器，为动态避障实验提供可控的动态干扰源。
      - nav_mon.py   该节点订阅导航、定位相关话题，采集小车位姿、协方差与导航状态信息并写入CSV日志，用于导航实验的数据记录与效果分析。
      - teb_auto_compare.py：TEB 参数自动对照测试脚本，自动备份、切换 TEB 规划器 yaml 参数，一键启动 Gazebo 仿真、障碍物节点与导航系统，测试结束后恢复原始参数，支持批量开展多组参数对照实验，并将测试备注写入 CSV 文件，实现自动化调参对比。
      - way_point_many.py：多点航点巡航脚本，预先配置多个导航目标点位，通过 move_base 的 action 接口依次自动下发导航目标，完成一个航点后自动执行下一个，无需在 RViz 手动点击目标，实现机器人连续自主巡点。
      - - `dtet.py`：激光雷达碰撞检测节点，读取`/scan`激光数据，设置距离阈值0.14m；当雷达检测距离小于阈值时，向`/collision_event`发布Bool碰撞信号，对接nav_monitor节点，用于记录碰撞事件。
      - - `prefer_left_simple.py`：简易优先向左绕行决策节点，订阅激光雷达和导航状态，检测前方存在障碍物时，下发向左绕行的速度指令，优先选择左侧绕开障碍，作为轻量自定义避障策略，辅助导航规划器。
    - urdf
      - camera.urdf.xacro：相机xacro模型，定义相机连杆、传感器参数、安装位置，仿真输出图像话题
      - car_base.urdf.xacro：小车底盘本体模型，定义底盘连杆、车轮、惯性与碰撞属性，机器人基础骨架
      - car_to.urdf.xacro：顶层汇总xacro，引入底盘、激光、相机模型，组装成完整机器人模型，供launch加载
      - laser.urdf.xacro：激光雷达xacro模型，定义雷达安装位置、扫描参数，仿真输出/scan激光数据
  - 练习SLAM lianxi_slam
    - launch
      - cmal.launch：AMCL定位启动文件，加载地图与定位参数，融合激光、里程计，输出小车全局位姿
      - gamapping_slam.launch：GMapping建图启动文件，接收激光数据，在线构建栅格地图，用于环境建图
      - map_saver.launch：地图保存节点，建图结束后导出pgm+yaml格式栅格地图
      - map_server01.launch：静态地图服务，加载yaml地图文件，为导航提供地图数据
      - move_base01.launch：move_base导航启动文件，采用DWA局部规划器，加载代价地图参数，接收目标点输出速度指令cmd_vel
      - test_to01.launch：导航集成测试launch，串联仿真、定位、地图服务、move_base，一键执行导航测试,要手动输入teb或dwa来决定导航方式
      - move_base_teb.launch：move_base启动文件，加载TEB作为局部规划器，设置控制频率、坐标变换容差，加载代价地图、全局规划器、TEB规划器相关yaml参数，同时配置costmap_converter转换插件，用于将代价地图障碍物转为多边形，供TEB局部规划器进行动态避障计算。
    - map
      - 03slam.yaml：栅格地图描述文件，配套pgm地图，记录分辨率、原点、占用阈值，给map_server加载
    - src1
      - obs_auto.cpp：障碍物处理C++源码，实现障碍物识别、跟踪相关逻辑，服务动态避障
     - param
       - `base_local_planner_params.yaml`：DWA原生局部规划器参数，设置速度上下限、加速度、路径跟踪权重、避障评价权重
       - `costmap_common_params.yaml`：代价地图公共参数，障碍物膨胀半径、传感器（激光）观测范围、障碍物判定阈值
       - `ekf.yaml`：EKF融合参数，融合里程计、激光定位输出平滑的全局位姿，配置各传感器协方差、融合开关
       - `global_costmap_params.yaml`：全局代价地图配置，地图更新方式、图层、静态地图开关，用于全局路径规划
       - `global_planner.yaml`：A*全局规划器参数，路径平滑系数、规划分辨率、是否允许穿过未知区域
       - `local_costmap_params.yaml`：局部代价地图配置，跟随小车实时滑动更新，用于近距离避障
       - `teb_local_planner_params.yaml`：TEB规划器参数，轨迹点数、时间分辨率、避障权重、速度约束、动态障碍物适配参数
    - world
      - box_house.world：Gazebo仿真场景文件，定义墙体、障碍物布局，搭建仿真环境，移动障碍物在这里生成，但不移动
贰、非项目主体，测试时用到，最终项目没有使用。
